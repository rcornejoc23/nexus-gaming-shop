# NEXUS Gaming Shop

Proyecto académico para la Evaluación Parcial 1 de Desarrollo Fullstack II.

## Funcionalidades principales

- Página principal con navegación y productos destacados.
- Catálogo generado desde un arreglo de JavaScript.
- Detalle dinámico de cada producto.
- Carrito de compras con `localStorage`.
- Registro con validación de RUN, correo, región, comuna y dirección.
- Login con validaciones de correo y contraseña.
- Formulario de contacto con validaciones.
- Sección Nosotros.
- Blog y dos páginas de detalle.
- Panel administrativo.
- Listado y formulario de productos.
- Listado y formulario de usuarios.
- Simulación visual de crear, editar y eliminar, sin backend ni base de datos.

## Cómo ejecutar

1. Abrir la carpeta en Visual Studio Code.
2. Abrir `index.html` con Live Server.
3. Para entrar directamente al administrador usar `admin/index.html`.

## Nota académica

Esta primera entrega corresponde a frontend. Las acciones administrativas de guardar y eliminar son demostrativas, ya que aún no existe una base de datos.
